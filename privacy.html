개인정보처리방침 (shorts-publisher)

shorts-publisher는 운영자 본인의 구글드라이브에 올린 숏폼 영상을 운영자 본인의 인스타그램·페이스북·유튜브 계정에 게시하기 위한 개인용 자동화 도구입니다. 운영자 외의 사용자는 없습니다.

1. 이용하는 정보

운영자가 지정한 구글드라이브 폴더의 영상·캡션 파일, 그리고 운영자 계정에 게시하기 위한 인증 토큰만 이용합니다.

2. 이용 목적

지정 폴더의 영상을 운영자 계정에 게시하고, 게시가 끝난 파일을 완료 폴더로 옮기는 데에만 사용합니다.

3. 보관 및 제3자 제공

인증 토큰은 GitHub Actions의 암호화된 저장소(Secrets)에만 보관합니다. 영상과 캡션은 게시 작업 중에만 임시로 내려받고 작업이 끝나면 삭제합니다. 어떤 정보도 판매하거나 제3자에게 제공하지 않습니다.

4. Google 사용자 데이터

Google API에서 받은 정보의 사용은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 접근 철회

운영자는 Google 계정 설정의 "타사 앱 및 서비스"에서 언제든 접근 권한을 철회할 수 있습니다.
